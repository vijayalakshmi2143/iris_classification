Iris Flower Classification Using Machine Learning
Overview
This project uses the Iris dataset to classify flowers into three species:
1. Iris-setosa
2. Iris-versicolor
3. Iris-virginica
A Decision Tree Classifier was implemented using Scikit-learn to predict the flower species based on sepal and petal measurements.
Technologies Used 
1. Python
2. Scikit-learn
Project Workflow
1. Load the Iris dataset
2. Split the dataset into training and testing sets
3. Train a Decision Tree Classifier
4. Make predictions on test data
5. Evaluate model performance
